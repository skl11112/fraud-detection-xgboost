# 财务舞弊风险检测项目

## 项目简介

本项目基于上市公司财务报表数据，使用 XGBoost 构建财务舞弊风险检测模型，并提供：
- 完整的特征工程流程（共线性过滤 + LASSO/XGBoost 双重筛选）
- 分层 5 折交叉验证 + LOOCV 评估
- SHAP 可解释性分析
- FastAPI 在线推理接口
- Agent Function-Calling 对接支持

## 核心功能

### 特征工程

1. **共线性过滤**：Pearson 相关系数 > 0.8 的特征对，保留与标签相关性更高的
2. **LASSO 筛选**：L1 正则化逻辑回归，系数非零的特征
3. **XGBoost 重要性**：特征重要性 Top 15
4. **交集策略**：取 LASSO 和 XGBoost 的交集，控制在 10-15 个特征

### 模型训练

- **Pipeline**：中位数填充 → 标准化 → XGBoost
- **交叉验证**：分层 5 折 CV（主评估）+ LOOCV（补充参考）
- **防过拟合**：max_depth=3，正则化参数，小样本适配

### SHAP 可解释性

- **离线分析**：全集计算 SHAP，生成 summary plot、force plot
- **在线推理**：每个样本实时单独计算 SHAP，不复用训练集结果

### API 接口

- **风险概率**：0-1 之间的舞弊风险概率
- **风险判定**：阈值 0.5，≥0.5 判定为高风险
- **SHAP 解释**：各特征对预测的贡献值
- **Top 因素**：影响最大的 3 个特征

## 项目规则（规则 A）

✅ 预处理全部在 Pipeline 内部，无全局 fillna / fit_transform  
✅ 最终特征数 10-15，经过共线性过滤  
✅ 使用分层 5 折 CV + LOOCV，未使用简单 train_test_split  
✅ 优先关注召回率，限制树深度防过拟合  
✅ SHAP：API 推理每个样本实时计算  
✅ API 返回字段完整，支持 Agent function-calling  
✅ 所有输出附带免责声明

## 免责声明

⚠️ **重要提示**：本模型输出仅为基于财务报表数据的统计风险预警，**不能直接定性财务舞弊**。模型基于有限样本训练，泛化能力存在局限。财务舞弊认定需结合审计证据、法律程序等多方面因素。
